# Crypto Watcher Bot

Private Telegram bot for personal crypto watchlists, price alerts (threshold and percent-move), on-demand price checks and optional morning summaries; owner gets aggregated stats.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
